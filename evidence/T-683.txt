T-683 - Editor explorer, diff, file picker and menus: keyboard, focus and honest messages (DT-C119; UX audit lane D, editor group)
Lane D (72), branch s-72/ux-3, PR #100, base e93a23ba (origin/main), code commits be6f4dfc and 5d026570, 2026-11-02.
Stacked beside #98 (T-678, DT-C114, s-72/ux-4): that PR covers chat, sessions and recovery, this one the editor. Merge after #98.

WHAT CHANGED
- Explorer: the Open-in menu closes on a click outside it, takes focus on its first item, closes on Escape from anywhere,
  walks with the arrow keys, gives focus back to its button and stays inside the window (new src/editor/menuNav.ts, also used
  by the diff actions menu). Open-in uses the Rocket icon; Expand all and Collapse all are double chevrons down and up.
- Explorer: Expand all marks a folder it could not read as "not readable" and says when it stopped at the 300-folder cap.
  The live refresh skips a folder whose last read has not come back yet (an asked-for read always goes). A drag ends cleanly
  when the system cancels the pointer. Escape cancels the delete question and returns focus to the tree. Escape in the content
  search closes it and focuses the tree; closing no longer fills the search box again.
- Empty Explorer, Add a project: choosing a folder when the project list is not on screen now adds it directly (a Git project,
  else a plain folder project) and asks the window to show the project list; the old dead-end text is gone.
- File picker (Quick Open): the arrow keys scroll the active option into view; a hover never scrolls.
- Diff: the actions menu (whitespace, wrap) works from the keyboard like the Open-in menu and is also on the embedded Changes
  bar. The "+" beside a line is drawn only where a review note can be saved (the embedded Changes view keeps its note cards
  but has no "+"). Deleting a review note shows "Review note deleted. Undo" for 8 seconds; Undo saves it again.
- All Changes tree: a greyed-out Viewed box has a title and description saying it waits for the diff to load.
- Close dialog (unsaved changes): Tab stays among its buttons; while a save runs the card holds focus so Tab and Escape stay inside.
- Editor headers: Copy reads "Copy path"; Preview, Front and Retry in the image and diff views are small buttons like the rest.
- Rich editor: a caret placed inside a link shows the link bubble, inside a code block the language list (Escape closes the bubble).
- spec: VIEW-059, VIEW-060, VIEW-061, EDIT-013, EDIT-014, EDIT-020, EDIT-021, EDIT-027, EDIT-029, EDIT-031, EDIT-035, EDIT-036,
  EDIT-037 and EDIT-043 Rules say the new behaviour; their Acceptance lines point here. No rule is reversed.

WHY
The night-of-2026-11-02 static UX audit of the editor (rows in proof/ux-audit/D-ux3.md, 18 rows: 17 fixed, one of them with a stale part, and 1 skipped for time) found menus a keyboard user could open but not use or leave, a note "+" that did nothing in the Changes view, an
Add a project row that ended in text telling the user to go elsewhere, and silent failures in Expand all.
