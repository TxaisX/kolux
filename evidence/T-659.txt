WHAT CHANGED (src-tauri/src/browser_preview.rs; one call site in browser_cli.rs)
1. Tokens: 16 bytes from the system random source (BCryptGenRandom on Windows via the windows-sys feature already
   enabled, /dev/urandom elsewhere), 32 hex characters, made the first time a folder is previewed and kept in memory
   for the run. Before: a fixed-key hash of the lower-cased folder path, the same on every run and machine.
2. Host check: serve() answers only a request whose header block has exactly one Host line equal to
   127.0.0.1:<port> or localhost:<port>; anything else gets 403 before any file is looked at.
3. Open-folder rule: add() and grant() take a predicate; the commands and the CLI pass opened(app), which accepts a
   folder inside a project, a project's workspaces folder or the shared workspaces folder (no Git), and only then a
   Git worktree whose .git file points back into that project's .git/worktrees. Both sides are compared as real
   paths; relative or missing folders are skipped. A refusal is an error string the callers already show.
4. Also: grant() no longer holds the preview lock while it checks folders; decode() no longer panics on a % before
   a multi-byte character.
