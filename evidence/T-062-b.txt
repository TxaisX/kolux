T-062-b (lane5/T-062-b, 2026-11-02): EDIT-044, the WSL-only rules for projects stored in a WSL distribution
==========================================================================================================

Scope built (pure logic, proven by unit tests on this Linux container; no WSL distribution here, DT-C41):
- Search of a WSL root (src-tauri/src/editor_search.rs): wsl_root() reads \\wsl$\<d>\... and \\wsl.localhost\<d>\...
  (either slash, case-blind share name, the \\?\UNC\ long-path form) into the distribution and the folder as Linux
  spells it; wsl_rg_command() runs "wsl.exe -d <distro> --cd <linux folder> -e rg <the local arguments>" (rg_args is
  shared with the local search, so both run the same ripgrep arguments). -e means no shell in between: the query
  reaches ripgrep as typed. Hits come back ./relative and map onto the root as a local search's do. search_gen picks it
  when wsl_root is Some. A missing wsl.exe is reported ("WSL is not installed here ..."), and inside the distribution
  code 1 with a message (a missing ripgrep or folder) is a failure with that message, not "no results". wsl.exe's
  UTF-16 messages are read as text (stderr_text).
- One file through its WSL path and its drive alias (src/editor/buffers.ts keyOf): \\wsl.localhost\<d>\mnt\c\...
  keys as c:/..., the two share names and both slashes key together, a non-/mnt path keys as //wsl/<distro>/<linux path>
  with the Linux path case-sensitive. keyOf is the one key the editor uses for open buffers, the two-tab rule and the
  change-detection stamps, so the two tabs share one text and one unsaved marker.
  Deviation from the triage brief: it proposed fsops::file_key used in files.rs. files.rs holds no map of open files
  (file_stamps answers per path in the order asked); every "same file" decision is keyOf in buffers.ts, so the rule
  lives there.
- Watcher (src-tauri/src/scm_watch.rs unwatchable): a WSL worktree is read every 4 s from the start, decided from the
  spelling alone (fsops::is_wsl), before the drive-type call, so no share is contacted. The 4 s read is the fallback
  that never goes quiet; no watcher runs inside the distribution (DT-C70; notify is refused, T-033-b).
