WHAT CHANGED (src/scm; 21 audit rows fixed, 1 skipped for time)
- ChecksPanel: Rerun failed jobs waits while it asks ("Asking..."), reads the checks again afterwards, and a failure
  shows in a red note (role alert); the note and the answer belong to the folder that was clicked, so a late answer
  after a folder switch is dropped. A link that will not open shows its reason in the note instead of nothing.
  The collapsed stack map (GIT-034) is mounted under the PR row, keyed by folder and pull request.
- CheckPane: Refresh button on the card, Retry beside a read error; the close button is named "Close the <name> check
  tab"; inline px styles moved to classes in src/scm/scmUx.css (OneClickNotice too).
- CommentsPanel: waiting state and error kept per comment or thread, shown under that card, its buttons wait; they clear
  when the folder or pull request changes. Reply is disabled, with a tooltip and a visible hint, when GitHub gave no id
  for the thread's first comment. Every comment box says "Enter sends. Shift+Enter adds a new line."
- PrStart: composer text kept per folder; Cancel clears, Escape (inside the form only) keeps; an open Base list takes
  the first Escape; the title box takes focus on open and focus returns to the opener; a finished AI write touches the
  kept draft only in the composer session it began in.
- ConflictPanel: a failed copy shows "Copy failed" on the button and a red note.
- AutoPrStatus: Dismiss on any line that is not running; Retry on a line that stopped on a failure runs the automatic
  flow again, after checking the automatic switch for that folder (a note says why when it is off or settings are
  unreadable); a running line has neither. A link that will not open shows the reason.
- One verb per action: Rerun failed jobs, Retry, Refresh, Fix with AI (the ChecksPanel button was "Fix with an agent"),
  Resolve with AI (was "AI resolve").
- New pure helpers src/scm/panelUx.ts; oneClick.test.ts assertion moved from a style string to a class.
- Skipped: LineNotes (its only home would be Source Control, SourceControlPanel is dead code, out of scope); not deleted.
- Spec: GIT-021, GIT-022, GIT-029, GIT-030, GIT-032, GIT-034 (spec/11-git-review.md) and EDIT-030 (spec/12-editor-files.md)
  Rules lines extended and Acceptance lines point here. GIT-032 is retitled to the new button name.

WHY
The Checks tab buttons did nothing visible while working, swallowed failures (a rerun, a copy, a link that would not
open), let one comment's action block or blame another, and lost a half-written pull request when the user switched
folder or pressed Escape. Static UX audit rows in proof/ux-audit/findings (listed in D-ux7).
