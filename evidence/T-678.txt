WHAT CHANGED
- Chat (src/chat): notes under the box clear themselves after 10 s; the zoom level shows for 1.2 s after Ctrl +, - or 0
  (a status region that stays in the page, so screen readers announce it); Copy on a message and Copy diff share one hook that says
  "Copy failed" when the clipboard refuses and goes back to its label after 1.5 s; a failed Load earlier messages says so under the
  button; the image overlay and the attachment preview take focus, close on Escape and give focus back; the two-browser link choice
  works with arrows, Home/End, Escape and a click outside, and focus returns to the link after the system browser opens; Space opens a
  link like Enter and links show a focus ring; the HandOff "Send result to" list closes on Escape (focus on its summary) and on a click
  outside, and that Escape never reaches the agent; web links in tool output, plans and notices go through the same link choice and
  "Open links in Kolux" setting as a link in a reply; the chat box has a visible focus ring; "Top" is "Scroll to start", "Expand all /
  Collapse all" are "Expand thoughts / Collapse thoughts"; the support check (chat_support) runs only while the window is visible.
- Sessions (src/sessions): Resume and Resume as chat ignore a second press while the first is starting (InFlight, 0.7 s); a disabled
  Resume says why in text under the row; Refresh shows "Scanning" only for a rescan the person asked for; the delete question names the
  session; Keep and Delete... pass keyboard focus to each other.
- Recovery (src/recovery): the crash report focuses Not now, closes on Escape from anywhere and keeps Copy Details off until the
  details load; a failed Restart in safe graphics / Try hardware again shows one line saying so.
- Spec: Rules and Acceptance of CHAT-008, 010, 012, 013, 014, 017, 021, 025, 026, 028, VIEW-020, 085, 086, 089, APP-039 and APP-043
  say the new behaviour, each new Acceptance line points here. No spec rule is reversed; the one changed meaning (tool-output links
  follow the link choice) is in DT-C114 and CHAT-013's Rules.

The 2026-11-02 cloud UX audit (proof/ux-audit/findings/chat-sessions.md, run on main e93a23b) found notes that never cleared, a silent
zoom, copies that reported success after failing, polling for hidden windows, double-started sessions, and small menus and dialogs a
keyboard could not leave or that did not give focus back. Rows closed (all "fixed" unless noted):

  findings/sessions/AgentsPanel.tsx.md:165, :322 and :201; findings/sessions/SessionFiles.tsx.md:50 and :12 (the backend check for a
  live session is skipped(time));
  findings/chat/StepRows.tsx.md:185 and :53; findings/chat/ChatView.tsx.md:356, :256, :321, :454, :377, :287, :530 and :194;
  findings/chat/ChatText.tsx.md:80 and :50; findings/chat/zoom.ts.md:34; findings/chat/chat.css.md:105.
  Skipped(time), size M: CrashReportDialog/ScreenBoundary inline styles; chat.css scrim/.btn refactor; AgentsPanel virtualisation.
