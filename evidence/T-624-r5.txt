  S2 (HIGH) decoded reference bypass       FIXED, TESTED.
     Before: relative_refs judged the raw text, then percent-decoded it, so `%2F%2Fhost%2Fs%2Fa.png` became
     `//host/s/a.png`, a UNC path; on Windows the copy would have contacted that server (NTLM leak).
     After: relative_refs decodes first, then safe_ref() refuses an empty ref, a leading / or \, any ':' or control
     character, a `..` part, a Windows device name (con, prn, aux, nul, com0-9, lpt0-9 ...) and anything that is not a
     plain relative path; inside() builds the path from plain parts and refuses a ':' in a part on Windows; copy_assets
     opens it with open_source(path, name, Some(folder)) (no canonicalize before the open) and derives the stored
     relative name from the final path of the opened handle.
     Tests: a_reference_is_judged_after_it_is_decoded (%2F%2F, %5C%5C, %2f%2f, C%3A, C%3a%5C, x.png%3Astream,
     x.png%3A%3A%24DATA, %2E%2E, a/%2e%2e%2f%2e%2e/, %2Fabs, ..%5C, NUL, con.txt, sub/COM1, %00, https%3A%2F%2F);
     a_decoded_unc_reference_is_never_opened_or_copied (a page naming them is kept, its plain assets are copied, no
     stored name holds ':' or the host); an_asset_reached_through_a_linked_subfolder_is_not_copied (a junction on
     Windows, a symlink elsewhere, to a folder outside the workspace holding secret.png); titles_and_refs (the
     decoded form comes through, a climbing reference does not).
  S3 (MEDIUM) reference count              FIXED, TESTED.
