BEFORE

AFTER
- menuEdit("edit.paste") is {field:"paste"} for a focused input, textarea or contenteditable (a
  field's normal edit path), and {terminal:"paste"} otherwise. Copy and Select All are unchanged;
  undo, redo and cut still do nothing in a terminal.
- The focused terminal takes the paste through the pane's own clipboard path (pasteRef ->
  pasteFromClipboard -> attachPaste): the 8 MB limit, one bracketed paste, the multi-line ask on a
  program without bracketed paste, and no typing into a pane that lost focus while the clipboard
  was read.
- A focused text field gets src/chrome/fieldPaste.ts: the clipboard is read, the selection is
  replaced at the caret with the engine's own input event (setRangeText on input/textarea, which
  the chat box already uses; execCommand("insertText") first on a contenteditable, with a Range
  fallback), maxLength respected, read-only/disabled refused, and the paste is dropped if the field
  lost focus during the read. A refused read says so in a toast instead of doing nothing.

  1,490,000 ceiling. Deferred, first load is 1,489,547 B (+149 over main 1,489,398, 453 under).
