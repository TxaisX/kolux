WHY
A program started by bare name can resolve to a copy planted in a folder Kolux does not control.
On Windows, Rust's std Command no longer searches the current folder (Rust 1.58+): it looks in the
app's folder, System32, the Windows folder and then PATH, so the remaining Windows exposure is PATH order. On Unix a
relative PATH entry resolves against the child's folder. Naming system programs by their full
path in the system folder, and other programs by a full-path lookup or a refusal, closes both.
