Source (public doc, cited in PROVENANCE.md 2026-11-02): Pi extension declarations
github.com/badlogic/pi-mono packages/coding-agent/src/core/extensions/types.ts, read 2026-11-02:
  BeforeAgentStartUserEvent { type: "before_agent_start"; messageType: "user"; prompt: string (the raw user prompt
  text after expansion); images? } for a run started by a submitted prompt, an RPC prompt or pi.sendUserMessage();
  BeforeAgentStartCustomEvent { messageType: "custom"; message } for a run an extension starts while idle;
  pi.on("before_agent_start", handler) where the handler may return a result (system prompt or message override) and
  Kolux's returns nothing. agent_start stays { type: "agent_start" } with no prompt, which is why main's card had none.
