What was built
- Settings > General > "Experimental" card: "Agent sleep" switch (agentSleep; off on a fresh profile and when the key is
  missing; only a saved true is on) and "Idle minutes before sleep" (agentSleepIdleMinutes; 30; held 5..240 before it is saved).
- One check a minute while the switch is on (no timer at all while off; no per-pane timers): src/sleep/useAgentSleep.ts.
- Eligibility (src/sleep/agentSleep.ts sleepRefusal): agent pane, not asleep, resumable session id (resumeId), program running,
  a hook state is known, not permission/waiting/open ask, finished (done or idle), no background tasks, no unsent draft,
  not the focused pane of a visible window, last state change older than the delay. Anything else: awake.
- Sleep: Rust `agent_pane_sleep` re-checks the switch, the pane's terminal and the agent in front of it, records the session
  (saved::at_pane_sleep, keyed by session like workspace sleep; a failed write is an Err and nothing ends), returns the terminal
  id; the window then marks the pane asleep (its terminal unmounts, which ends only that pane's Job object), drops its pty entry
  and running flag, and ends the terminal by id. Placeholder: "Asleep to save memory · idle N min" + Wake (src/sleep/AsleepPane.tsx).
- Wake: agent_start_line { restore: true, session } (the same call main.tsx makes for a restored tab), the key added to
  restoredKeys so the terminal remounts as a restored tab (kept output replayed, a failed start keeps the tab with its reason).
- Docs: TERM-123 and HID-028 cards (state, rules, acceptance ticks with proof), DECISIONS.md DT-C242 (+ the two "skip" rows
  updated), docs/guide/settings.md "Experimental", PLAN.md T-817, STATE-history line.

Runtime proof
- Not run. A live sleep needs an agent that reports a finished turn with a resumable session id through the hook listener
  (DT-C240 per-pane tokens). No Claude or Codex login exists in a scratch profile and the owner's credentials may not be used;
  the repo has no stand-in agent that speaks the hook protocol, and writing one plus a dev build of the app did not fit the
  lane's turn budget. The development-only `agentSleepTestFast: true` setting (20 s delay, 5 s check; never read by a release
  build) is in place for that proof: start the dev app with a scratch profile, open an agent, let a turn finish, unfocus the
  pane, and watch the placeholder appear within about 25 s, then Wake.
