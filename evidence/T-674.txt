  inside, close on Escape (only a dialog marked aria-modal="true" or a confirmation over it takes it, so a docked
  tip card or the floating workspace panel never does; an Escape in the sign-in terminal stays
  with the terminal) and give focus back. Explore and the Setup Guide close when Settings opens from
  their own Open Settings buttons, a palette Settings page or Ctrl+, (SETTINGS_SHOWN), so Settings is not left
  behind them. The native menu's Settings item (src/settings/useSettingsPlumbing.ts, lane E1) is requested in
  proof/ux-audit/requests/E1.md. On macOS Cmd+, is that native menu item, so it waits on the same
  request.

  no agent installed (NO_AGENT_NOTE, src/onboarding/useWizard.ts), missing GitHub
  sign-in naming gh auth login (ConnectGithub.tsx); the Accounts step opens Settings > Accounts.
- Hooks card (Guides.tsx, hooksOn.ts): Not now and Turn off are separate; a later skip records nothing.
- Tours (tour.ts, Tours.tsx): a replay that cannot start says why; the tours hint is visible.
- Help sheet (helpItems.ts, HelpSheet.tsx): Report Crash after Send Feedback, like the native Help menu.
- Trust prompt (src/setup/TrustPrompt.tsx): says what is remembered. Keyboard hints follow the
  platform (submitKeys.ts). A double click starts nothing twice (once() in agentstart/host.ts).
- spec/16-onboarding.md: ONB-004, ONB-005, ONB-015 and ONB-020 Rules changed (DT-C110), each with an
  acceptance line pointing here.
