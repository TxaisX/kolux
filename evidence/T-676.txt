T-676 - Git steps never wait or hang, and the Changes tab stages, unstages, pushes, pulls and syncs (DT-C112; GIT-002/004/007/038/063/070, EDIT-029; UX audit lane D)
Lane D (72), branch s-72/ux-1, PR #101, base e93a23ba (origin/main), code commits 4ada2e9a, 84673d1a, f5f87cbe (head), 2026-11-02.

WHAT CHANGED
- scm.rs: every push, pull, sync and fetch Kolux runs (and the push before a pull request) goes through
  git_network(): terminal and credential prompts off (GIT_TERMINAL_PROMPT=0, GCM_INTERACTIVE=never),
  no input, and a 600 s limit that kills the git process tree. A stopped step comes back as a
  network-kind failure saying it timed out and naming likely causes (slow remote, large push, slow
  pre-push hook, sign-in that cannot be shown). A rebase is a local step and has no limit. Output a
  program keeps open after git exits costs at most a short wait and is not lost.
- scm.rs: scm_stage, scm_discard, scm_commit, scm_remote, scm_abort, scm_commit_files and
  scm_base_sides run on a blocking thread, not the async runtime.
- scm.rs: unstaging before the repository's first commit uses git rm --cached -f (there is no HEAD
  to restore from) and leaves the file on disk; History fetches one extra commit and marks the last
  one `capped: true` when older ones were cut off (no UI shows it yet; SourceControlPanel is unmounted).
- changesActions.ts + AllChangesPane.tsx (the live Changes tab): Stage / Unstage on each file's
  section header (working-tree view), Stage all, Unstage all, Push, Pull, Sync with counts and the
  reason a disabled one waits, a pending line and an error line, one git action at a time (Commit
  waits too), a re-read of the status after each action that yields to a newer watcher status.
  Stage all / Unstage all on a list the back end cut short send "." (the whole worktree), except
  Stage all when conflicts exist sends only the rows listed; a staged rename unstages both its old
  and new path.
- The commit box shows in both the working-tree and the branch-vs-base views; the commit hint names
  Stage all / per-file Stage; Retry on the load error; Make default says "Saved" or "was not saved;
  try again"; Inline / Side by side switch; the tree resize handle ends on a cancelled pointer and on
  unmount, is focusable and moves with arrow keys (+-16), Home and End.
- spec: GIT-002, GIT-004, GIT-007, GIT-038, GIT-063, GIT-070 (11-git-review.md) and EDIT-029
  (12-editor-files.md): Rules/User sees say what changed; their Acceptance lines point here.

WHY
The cloud audit (proof/ux-audit/findings/{scm,editor-a,stress}.md, at main e93a23b) found that a push
or pull could hang the app for good on a password prompt no one could see, that git calls blocked the
app's async runtime, and that since T-644 removed the Source Control panel the live Changes tab could
read changes but not stage, unstage, push, pull or sync. Rows (from D-ux1.md, all fixed):
