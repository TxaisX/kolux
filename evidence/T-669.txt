THE ISSUE
The UX audit (proof/ux-audit/findings/usage-status.md) found the Resource Manager popup lost a failed End's error on the
next read, let End all and Restart terminals be pressed again during a run, closed the whole panel on Escape with an End
question open, took no focus and had unnamed End buttons; its poll could start a read while one was still running. The
token panel showed nothing when token_usage failed, swallowed failed Track switches, rescans and project-list reads, had
an unlabelled switch, figures only in tooltips, a Share button with no CSS and a Share dialog with no focus handling, and
made a new Date on every render. The Insights panel's "Turn it on in Settings → Usage" was plain text and gave no way to
the sessions past the eight it shows.

WHAT CHANGED
- src/status/ResourceManager.tsx + resources.ts: an End error stays until dismissed; End all / Restart greyed while a run
  is going; Escape closes the open question first (escapeStep: bulk, single, End N), then the panel; the popup takes focus
  on open through chrome/dialogFocus useDialogFocus (box is tabIndex -1, so not a Tab stop) and gives it back; End buttons
  named for their session; the poll runs through singleFlight, so a tick while a read runs does nothing.
- src/usage/TokenAnalytics.tsx + analyticsNotes.ts (new): a failed token read shows the error with Retry (the error stays
  until the read works); failed Track switch, rescan and project-list read are named in one always-present role=status
  region; an unreadable project list falls back to every local use; the switch is "Track <provider> tokens"; chart bars
  and heatmap cells carry their figures as labels; one memoised today and row list.
- ShareButton.tsx uses .btn; ShareCard.tsx uses useDialogFocus (its own window Escape listener is gone); StripTotals.tsx
  puts its label on a role=group element.
- src/insights/InsightsPanel.tsx + insights.css: the Settings → Usage hint is a button that opens that page; more than
  eight sessions adds "More sessions in Settings → Usage".
Rows: usage-status.md 2, 3, 4, 6, 7, 8, 9, 10, 11, 14, 15, 16, 17, 18, 19, 20 fixed (16). Skipped: row 12 (see REVIEW).
Not here: rows 5 and 13 (StatusBar), they ride in T-688. None stale.
