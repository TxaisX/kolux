1. What the user gets
- An agent tab without status hooks (Cursor, Gemini CLI, Hermes, Goose, Amp: the five rows of SOURCES with a sessions
  command) comes back resumed after a quit, the way a Claude Code or Codex tab does: when the layout is written down,
  Kolux runs the agent's own sessions command in the tab's folder and takes the newest session listed there that no
  other tab holds. An id the agent printed itself (its exit hint, T-066-d source 1) or a hook's id is never replaced.
- Two tabs of one agent in one folder never get the same session (each answer is added to `taken` for the next ask).
- A sessions command that hangs is killed after 5 s and gives nothing; a missing program gives nothing; a layout save
  never waits on it (the ask runs beside the write and the id rides the next write). The 5 s bound the whole ask,
  the reading of the output included: a helper the command leaves behind holding its output (an updater, a daemon)
  never holds the ask past it, and what the command printed before it exited is still its list (review fix).
- A listed id is a guess until the agent names its own (review fix): a tab is asked the moment it is opened, before
  its agent has made a session, so the folder's previous session may be put on it first; the tab is asked again
  (every 30 s, its own guess left out of its ask) and the session its agent made since replaces the guess; the id
  the agent prints itself when it exits wins over the guess. An id the agent named itself (a hook, its hint) is never
  replaced, by a list or by a later hint.
- Only the five agents with a sessions command (Cursor, Gemini CLI, Hermes, Goose, Amp) are asked; a Kiro, Aider,
  Copilot or other tab is not (nothing to run).

2. What changed
- src-tauri/src/terminal.rs: listed_session(program, src, folder, taken) runs `program` with `src.list` in `folder`
  (stdin null, stdout piped and read on a thread, stderr null, CREATE_NO_WINDOW on Windows), try_wait loop, killed at
  LIST_WAIT (5 s; taskkill /T on Windows), at most LIST_CAP (256 KB) read, then session_id::pick_listed. The .cmd shim
  case goes through pty::start_line_on as every other agent start does.
  terminal_listed_session(agent, folder, taken) (async, spawn_blocking): Ok(None) for an agent with no list source or no
  program found; the program is the user's own command for the agent when set, else agents::installed_program (now
  pub(crate)); Err only for an empty folder.
- src-tauri/src/lib.rs: the command registered next to terminal_forget_history.
- src-tauri/src/terminal_session_id.rs: `#![allow(dead_code)]` and its ponytail note dropped; the module comment names the caller.
  Review fix: the reader thread hands its output over an mpsc channel a piece at a time; once the child has exited the
  pieces are taken with recv_timeout(LIST_WAIT - elapsed) until the pipe closes or the wait runs out, and what arrived
  is parsed. The reader is never joined (it ends when the pipe closes or when nobody takes its pieces).
- src/terminal/layout.ts: panesWantingListedSession(panes) -> { asks, taken }: a started tab of an agent in
  LISTED_AGENTS (cursor, gemini, hermes, goose, amp: the SOURCES rows with a list) with no session, or only a listed
  guess (`sessionListed`, a LivePane-only field layoutOf never writes), is asked, with its folder and, for a guess,
  `own` (left out of its own ask so the same or a newer id can come back; it stays in `taken` for the others); a
  chooser never started, a non-terminal tab, a tab with no folder, a hook-fed agent and an agent with no sessions
  command are not; `taken` is every session id some pane holds plus each fork's source.
  withListedSession(panes, key, id): the list's answer goes on the pane as a guess while it has no id or a guess.
  withHintedSession(panes, key, id): the agent's exit hint goes on the pane over no id or a guess, never over a settled id.
- src/shell/useWindowSave.ts: when the layout effect writes, askListedSessions runs: one round at a time, the asks in
  turn, each answer pushed to `taken` and put on the pane through withListedSession; a pane asked is left alone for
  LISTED_ASK_AGAIN_MS (30 s) since a layout write comes with every focus move. src/App.tsx passes setPanes and the
  Pane type carries sessionListed. src/projects/useCliBridge.ts puts the exit hint on through withHintedSession.
- docs/guide/projects-and-worktrees.md (agent sessions table and paragraph), docs/guide/feature-index.md (a T-066-d/e row).
