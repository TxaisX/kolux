G1 [wrong?] Palette "Filter by repository" / "Filter by kind" selects do not change - NOT REPRODUCED (by design).
  The two selects are pickers: each holds its prompt ("+ Repository", "+ Kind"), and picking an entry adds a filter chip
  and puts the picker back on its prompt (VIEW-041). The harness read the select's own value, which goes back to "" on
  purpose, so it saw "no change". Test "G1 (not reproduced)": picking a repository adds "Repository: app", picking a kind
  adds "Kind: Worktrees", each picked entry leaves its picker, and the chip's button removes it again.

G5 [polish] Ctrl+Shift+E never hides the Explorer - NOT REPRODUCED; the action's name now says it hides.
  Code path: Ctrl+Shift+E runs sidebar.explorer.toggle (useWindowKeys.ts), which calls toggleExplorer
  (useSettingsPlumbing.ts): with the Explorer open and focus inside .explorer it hides it; otherwise it shows the Explorer
  and asks it to focus its tree (Explorer.tsx focuses the tree box, which sits inside <aside class="explorer">). The global
  scope stays active with focus in the tree (keyScopes.ts: inTree -> global, tabs). So the first press shows and focuses,
  the second hides. The harness's second press most likely came with focus elsewhere (it sends keys over CDP).
  Change: the action's name "Show Explorer" becomes "Show or hide Explorer" (src/keys/actions.ts; COMPAT.md and
  docs/guide/terminals.md follow). Test "G5 (not reproduced)" pins the hide branch, the focus target inside the panel,
  the scope and the new name.

G6 [polish] Find bar: Previous/Next with no matches shows nothing - FIXED.
  The bar already said "No matches" for text with no match (countLabel, find.test.ts). The harness's shot
  (G:/Temp/live-wave3/shots/S25-find-bar.png) has an empty query: the harness typed and removed its text, then clicked
  Previous/Next, which then did nothing with no word said. Change (src/terminal/FindBar.tsx): Previous and Next are
  greyed out and disabled while there is nothing to step to (count 0: no text yet, or No matches). Test "G6": with
