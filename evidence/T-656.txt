What changed
- `kolux set headers` / `kolux set credentials` record one site (the tab's page, or --origin). Clearing headers works on any tab.
- The app hands a page on another site blank values (and no site name); the page script adds them only when the page and the
  request's resolved address are both on that site, for fetch and XHR, and sends the request to exactly the address it checked.
- The page script keeps the built-ins it relies on from before any page script runs; the hand-in function cannot be replaced.
