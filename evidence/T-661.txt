T-661 · a page's request to leave Kolux or drop a certificate's trust asks first (audit backlog row 57 / #91-m1; DT-C97)
branch s-90/t661 · 2026-11-02 · worker 90, coordinator 57

THE ISSUE
The browser tab's right-click menu is drawn inside the page, so a pick reaches Kolux as the page's word plus a user
gesture the page may have steered. "Open in default browser" ran straight away on such a pick, and so did a sized
window a page opened before its first load finished (that route goes to the system browser). Leaving Kolux hands the
address to another program with the user's real profile, so the user must see where it goes before it happens.

WHAT CHANGED
1. src/browser/leave.ts (new): the ask. Only an http(s) address is offered; the host and the address are the parsed
   ones (punycode, any user name before an @ dropped); the shown address is capped at 300 characters; the confirm
   counts only 600 ms after the ask appeared, on the ask's own clock, so a replacing ask waits again.
2. src/browser/BrowserPane.tsx: "Open in default browser" picks and the browser-leave event raise Kolux's own bar
   above the page (the place of the existing outbound-preview ask, which the page's view cannot cover):
   "Open <host> in your default browser?", the address, a button "Open <host>" and Cancel. Only Open calls
   open_external. "Stop trusting" from the menu gets the same ask, only for the site on show, one at a time, and only
   when Kolux's own certificate state says it is trusted. A new page load or the tab going behind drops the ask, and an
   ask whose state check returns after either is not raised. "Open in Kolux" is unchanged.
3. src-tauri/src/browser.rs: the Route::System popup emits browser-leave and denies the window instead of opening the
   system browser; pick_allowed's doc updated (open-default picks still count against the tab family's allowance).
4. src-tauri/src/browser_certs.rs: the engine's remembered certificate allowances are cleared only when a revoke really
   dropped a trust.
5. src/browser/browser.css: the ask's buttons stay on one line.
Certificate Trust gets no ask: a page cannot reach it. Tauri refuses an app command from a remote page unless a
capability names it under remote, and none does; a unit test reads every capability file and the live proof has the
page call the command itself.
