T-660 - Programs Kolux starts are never looked up in the current folder (DT-C96; audit backlog rows 49 and 50)
Worker 2f, branch s-2f/bare-name-spawn, base 6540632a (main merged at e34b3e59 and fa163d5c), 2026-11-02.

WHAT CHANGED
- cmd.exe is started by its full path in the system folder Windows reports (GetSystemDirectoryW;
  else %SystemRoot%\System32, else C:\Windows\System32) for the community skills installer, for
  command-script shims, and as the automatic and menu Command Prompt. The prompt's UTF-8 switch runs
  chcp by its full path too, so cmd.exe never looks for chcp in the pane's folder. ComSpec is used
  for the automatic pick only when it is a full path to a file.
- The menu's Windows PowerShell entry falls back to its System32 path when no lookup finds it. The
  non-Windows fallback shell is /bin/sh, not a bare sh.
- Every pane start (PtySession::spawn_first, the one path every terminal, agent and shell goes
  through) checks its program first. A name without a full path is looked up in the full-path
  folders of the PATH the pane is given, then in the app's own search folders, and swapped for
  what is found. A command script found that way starts through the same shim handling as any
  other (T-605). A name not found there, or one with a separator or drive in it (./x, bin\x, C:x),
  is refused with a message naming it. program_command no longer wraps an unresolved name in
  cmd.exe.
- scm_writers.rs (one line, a follow-on): the writer's "a command script cannot take a prompt with
  line breaks" refusal compared against the bare name "cmd.exe"; it now compares against the full
  path, so the refusal still fires.

WHY
A bare name reached Windows (CreateProcess searches the app's folder) or the terminal library (on
Unix it joins the pane's folder with relative PATH entries), and cmd.exe itself looks in its current
folder first, so a cloned project could plant its own cmd.exe, chcp or tool and have Kolux start it.

- the automatic shells and the menu name only full paths, none in the planted folder.
