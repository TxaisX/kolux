WHAT THE USER GETS
- When an agent finishes a turn with changes, Kolux commits on the workspace's own branch. With a
  remote it pushes that branch and opens or updates a draft pull request into the default branch.
  With no remote it only commits, and a "local only" icon says so.
- Settings -> Git & worktrees: automatic pull requests On / Off / default per workspace, with one
  default (on for GitHub repositories only).
- One click (the manual flow) no longer drops files past the first 1,000 (audit row 8).

GUARDS (DT-C90), each refused in Rust with the files named
- Never the default branch, never force, never tags or submodule commits
  (push --no-follow-tags --no-recurse-submodules -- origin <commit>:refs/heads/<branch>).
- A likely secret (by name or by a well-known key prefix in the content, commit messages included)
  or a file over 10 MB stops the commit and the push. The scan reads the blobs git would commit or
  push, after filters, in batches; every history read has a 10-minute limit and a timeout fails.
- Only inside a Kolux workspace; a branch pushing to a fork or another remote is skipped.
- git's index.lock is never deleted: a held lock skips the turn, and the message says how to find
  and clear a lock a stopped git left behind.
- A branch already on origin whose link or local copy of origin/<branch> is missing or behind is
  repaired on a later run without pushing again, so the draft pull request still opens.
