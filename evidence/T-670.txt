WHAT CHANGED
- Task dialog: a failed load now says "This could not be read from GitHub" with a Retry button, not
  "Loading…" forever. An unsaved description is kept while Kolux runs and comes back in the editor when
  the same item is opened again. Closing the dialog gives focus back to what had it; a button that goes
  away (a label x, Close issue) hands focus back to the dialog. The close button and the label and
  assignee x buttons have names and a 20 pixel hit area.
- Pull request page: Escape goes back to Tasks, unless a text field, menu, dialog or an edit is open
  (an open merge confirm closes first). The button is "Back" with an arrow, not an X. A Refresh button
  replaces Reload. A failed checks or review-threads read puts a note above the tabs instead of showing
  an empty list. "Yes, merge it" is the red danger button.
- Workspace board: a failed load shows the error with Retry; projects whose workspaces could not be
  listed are named with a Retry; a board with no workspaces says so; a failed move says the cards were
  put back.
- Inbox: Enter and Space on the detail pane's buttons work again (the list no longer takes them); a
  failed status read says "Could not read the changes" instead of "No files changed"; the selected row
  scrolls into view.
- Tasks list: the pager stays on an empty page after the first, so you can go back.
- Projects view: failures have a Retry. "Chosen repositories" starts with the project's repositories
  that are open in Kolux ticked, else all of the project's repositories (never an empty table).
- Issue actions: a read-back that fails after a good change says so and no longer puts the change back.
- tasks.css: the GitHub green and red, the code and border greys use the theme colours (done, danger,
  line). styles.css is untouched.
