T-673 - Keys and the native menu (DT-C109; SET-013, VIEW-002, APP-009; UX audit lane C)
Worker 49, coordinator 57, branch s-49/ux-1 (PR #104), 2026-11-02.

WHAT CHANGED
- Default chords (src/keys/actions.ts): Rename active tab Ctrl+Shift+G, Maximize floating workspace
  panel Ctrl+Shift+Backslash, Minimize it Ctrl+Shift+H on Windows and Linux (macOS keeps its chords;
  Minimize gets Cmd+Shift+H). New command Move Focus to the Top Bar, Ctrl+Shift+P (Cmd+Shift+P),
  which a focused terminal passes through. New palette command Open Automations (unbound). A test
  fails if two default chords clash in a shared scope on any platform.
- Window keys (src/keys/useWindowKeys.ts): an app chord (global, tab or terminal scope) waits while a
  menu, popover or modal dialog is up. Docked tips, tours (aria-modal="false"), the floating
  workspace, agent question cards, the plan sheet, the update card and inline sidebar forms hold
  nothing, and neither do the source-control and pull request inline forms or the browser's grab sheet.
  Only the browser chords the window runs itself (address bar, back, forward, reload, find) are held;
  a page's own chords, editor and explorer chords never are, so Ctrl+C still copies in a page.
  Ctrl+W asks the focused pane first (kolux:pane-close), so a pane with its own warning can claim it (no pane listens yet: a hook for lane D).
  Back/Forward say why nothing happened (Settings open, wrong screen, no earlier/later workspace).
- Native menu (src-tauri/src/menu.rs): View > Workspace View lists Space; View has no plain Reload
  (Force Reload stays); Developer Tools only in debug builds; Help > Report Crash on every platform.
- Worktree palette: worktree lists load in parallel; unnamed sections sort after named ones.
- spec: SET-013 Rules/Compat (138 commands, 82 with a chord, 56 without; the chords above), VIEW-002
  (Space in the submenu), APP-009 (View menu); each has an acceptance line pointing here.

WHY
UX audit keyboard/palette rows (proof/ux-audit/findings/keyboard.md, palette.md): Windows and Linux
users had no chord for several commands, no way out of a focused terminal by keyboard, shortcuts that
fired behind open dialogs, a Reload menu item one click from throwing away unsaved edits, and a
Space view missing from the menu.
