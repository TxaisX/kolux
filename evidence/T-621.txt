T-621 · The screen switcher fits its four segments and the right group never covers it · lane2/product-ux-2 · 2026-10-31
Proved in the Linux cloud sandbox: Chromium (Playwright) on the real TopBar with the app's styles.css and its own
font (applyAppearance, the Inter / Segoe UI stack), served by Vite, the T-620 harness rebuilt from evidence/T-620.txt
(dist/drag-harness, git-ignored). Nothing was run on Txais's PC.

FOUND
- The frame was 210 px but its segments need 277 px (68 + 61 + 86 + 62) plus gaps: Tower stuck out.
- .topbar used grid columns 1fr auto 1fr. The right group's column could be narrower than the group, which then
  reached left over the switcher (at 1280 the column was about 600 px for a 791 px group).
- Also found: at 900 and 1000 px the window controls were drawn past the window's right edge (Minimize, Maximize
  and Close at 900; Close at 1000): the whole bar needed about 1,120 px.

WHAT CHANGED (src/styles.css only; TopBar.tsx untouched, so T-620's drag attributes are exactly as they were)
- .switcher: width max-content (its four segments).
- .topbar: grid-template-columns minmax(max-content, 1fr) auto minmax(max-content, 1fr): centred while it fits,
  and no side column is ever narrower than its content.
- @media (max-width: 1365px): columns max-content auto minmax(0, 1fr): the switcher follows the left group and the
  right group takes the rest, never more than its column (max-width 100%, overflow hidden); only the account pill
  (its name ends in an ellipsis, min 44 px) and the usage pill (min 56 px) shorten, so the window controls stay on
  screen down to the 900 px minimum.
  ponytail: the usage pill is clipped, not ellipsised, at the narrowest widths (its figures are several spans).
- src/chrome/topBarLayout.test.ts (new): guards those rules in the stylesheet (unit level; the geometry is the
  browser run below).

// T-621 experiment: apply candidate CSS over the app's and measure the bar at each width.
const { chromium } = require("playwright");
const css = process.argv[3] || "";
(async () => {
  const b = await chromium.launch();
  for (const width of [900, 1000, 1100, 1280, 1365, 1366, 1400, 1600, 1920]) {
    const p = await b.newPage({ viewport: { width, height: 300 } });
    await p.goto(process.argv[2]); await p.waitForSelector("header"); await p.waitForTimeout(300);
    if (css) await p.addStyleTag({ content: css });
    await p.waitForTimeout(100);
    const g = await p.evaluate(() => {
      const R = (s) => document.querySelector(s).getBoundingClientRect();
      const nav = R("nav.switcher"), right = R(".topbar-right"), left = R(".topbar-left"), header = R("header");
      const segs = [...document.querySelectorAll("nav.switcher button")];
      const covered = segs.filter((s) => { const r = s.getBoundingClientRect(); const hit = document.elementFromPoint((r.left + r.right) / 2, (r.top + r.bottom) / 2); return !s.contains(hit); }).map((s) => s.textContent);
      const last = segs[segs.length - 1].getBoundingClientRect();
      const outside = [...document.querySelectorAll("header button, header .usage")].filter((n) => n.getClientRects().length && n.getBoundingClientRect().right > innerWidth + 0.5).map((n) => n.title || n.className);
      const kids = [...document.querySelector(".topbar-right").children].filter((c) => c.getClientRects().length).map((c) => Math.round(c.getBoundingClientRect().width));
      return { leftRight: Math.round(left.right), navLeft: Math.round(nav.left), navRight: Math.round(nav.right), lastSeg: Math.round(last.right), rightLeft: Math.round(right.left), rightRight: Math.round(right.right), centreOff: Math.round((nav.left + nav.right) / 2 - innerWidth / 2), covered, outside, kids };
    });
    console.log(width, JSON.stringify(g));
    await p.close();
  }
  await b.close();
})();
